# Оповещения Ялты, вариант 2

Бесплатный MVP: уполномоченный человек пересылает сообщение из Telegram боту, бот проверяет текст и отправляет Web Push подписчикам PWA-сайта.

## Как работает

1. Пользователь открывает PWA и разрешает уведомления.
2. Уполномоченный Telegram-пользователь пересылает публикацию боту или отправляет `/alert текст`.
3. Бот принимает только сообщения от ID из `ADMIN_TELEGRAM_IDS`.
4. Сообщение отправляется, если содержит `БПЛА`, `беспилот`, `дрон`, `воздушн` или `ракет`, либо начинается с `/alert`.
5. Сервер сохраняет сообщение и отправляет Web Push всем подписчикам Ялты.

## Запуск

Нужен Node.js с поддержкой `fetch` и HTTPS на публичном адресе.

```bash
npm install
cp .env.example .env
npx web-push generate-vapid-keys
npm start
```

Сгенерированные VAPID-ключи внесите в `.env`. Токен бота не публикуйте и не отправляйте в чат.

В `PUBLIC_URL` укажите HTTPS-адрес сайта. После запуска сервер автоматически зарегистрирует Telegram webhook.

## Создание бота

1. Откройте `@BotFather` в Telegram.
2. Выполните `/newbot`.
3. Сохраните токен только в переменной `TELEGRAM_BOT_TOKEN`.
4. Узнайте свой Telegram user ID и внесите его в `ADMIN_TELEGRAM_IDS`.
5. Откройте бота и отправьте ему тестовое сообщение или пересланную публикацию.

## Важно

Это независимый информационный сервис, не замена официальным каналам экстренного оповещения. Перед публичным запуском добавьте подтверждение сообщений, журнал действий, резервный канал и проверку источника.
