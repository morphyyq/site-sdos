# Ялта · Оповещения

Минималистичный PWA-сервис для уведомлений по Ялте. Уполномоченный человек пересылает сообщение Telegram-боту, сервер проверяет текст, сохраняет его в MongoDB Atlas и отправляет Web Push подписчикам сайта.

## Схема

```text
Telegram → бот → Render → MongoDB Atlas
                         ↓
                    PWA и push
```

## 1. GitHub

Загрузите содержимое этой папки в корень приватного GitHub-репозитория. Не загружайте `.env` и токены.

## 2. MongoDB Atlas

1. Создайте аккаунт MongoDB Atlas.
2. Создайте бесплатный кластер, если бесплатный тариф доступен в вашем аккаунте.
3. В `Database Access` создайте пользователя базы данных с сильным паролем.
4. В `Network Access` добавьте IP `0.0.0.0/0`, если используете Render с динамическим IP. Ограничьте права пользователя только нужной базой.
5. Нажмите `Connect` → `Drivers` → `Node.js` и скопируйте connection string.
6. Замените в строке `<password>` на пароль пользователя базы.

Переменные для Render:

```text
MONGODB_URI=mongodb+srv://USER:PASSWORD@cluster.example.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB_NAME=yalta_alerts
```

Пароль не должен содержать специальные символы без URL-кодирования. Проще использовать пароль из букв и цифр.

## 3. Telegram

1. Откройте `@BotFather`.
2. Выполните `/newbot`.
3. Сохраните токен в Render, но не загружайте его в GitHub.
4. Узнайте свой Telegram user ID.
5. Добавьте его в `ADMIN_TELEGRAM_IDS`.

Бот принимает сообщения только от ID из `ADMIN_TELEGRAM_IDS`.

Сообщение можно переслать боту или отправить вручную:

```text
/alert Фиксация БПЛА в районе Ялты
```

Без `/alert` сообщение должно содержать слова вроде `БПЛА`, `дрон`, `беспилотник`, `воздушный` или `ракета`.

## 4. Render

Создайте `Web Service` из GitHub-репозитория:

```text
Build Command: npm install
Start Command: npm start
```

Добавьте переменные окружения:

```text
TELEGRAM_BOT_TOKEN=
ADMIN_TELEGRAM_IDS=
PUBLIC_URL=https://ваш-сервис.onrender.com
TELEGRAM_WEBHOOK_SECRET=
MONGODB_URI=
MONGODB_DB_NAME=yalta_alerts
VAPID_SUBJECT=mailto:ваш-email@example.com
VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
```

VAPID-ключи можно получить командой:

```bash
npm install
npx web-push generate-vapid-keys
```

После запуска сервер создаст нужные индексы MongoDB и зарегистрирует Telegram webhook.

## 5. Пользовательская инструкция

### iPhone

1. Открыть сайт в Safari.
2. Нажать `Поделиться`.
3. Выбрать `На экран Домой`.
4. Открыть сайт с новой иконки.
5. Нажать `Включить`.
6. Разрешить уведомления.

### Android

1. Открыть сайт в Chrome.
2. Нажать `Включить`.
3. Разрешить уведомления.
4. При желании добавить сайт на главный экран.

## Важные ограничения

Сервис независимый и не заменяет официальные системы оповещения. Push-уведомления зависят от разрешений пользователя, настроек телефона и интернет-соединения.

Бесплатные тарифы MongoDB Atlas и Render имеют ограничения, которые могут меняться. Перед публичным запуском проверьте лимиты, добавьте подтверждение сообщений и резервный официальный источник.
